| Shortcuts | Functionality |
|-----------|--------------|
| cmd-k v / ctrl-k v | Open preview to the Side |
| cmd-shift-v / ctrl-shift-v | Open preview |
| cmd-k shift-l / ctrl-k shift-l | Open locked preview to the Side |
| cmd-k cmd-shift-l / ctrl-k ctrl-shift-l | Toggle preview lock |
| ctrl-shift-s | Sync preview / Sync source |
| shift-enter | Run Code Chunk |
| ctrl-shift-enter | Run all Code Chunks |
| cmd-= / cmd-shift-= | Preview zoom in |
| cmd-- / cmd-shift-_ | Preview zoom out |
| cmd-0 | Preview reset zoom |
| esc | Toggle sidebar TOC |
